Entry for the make.fun bounty [Worst Superpower](https://make.fun/c/u-suroto-worst-superpower-461dcdbe?utm_source=github&utm_medium=readme&utm_campaign=worst-superpower).

`main.py` writes the superpower to `/output/entry.txt`:

> I can tell when an avocado is perfectly ripe — but only by cutting it open. Four hundred in, the answer is always yesterday or tomorrow.

The line was picked by duelling twelve drafts against the competition's
published judge brief (genuinely useless first, then the laugh, then the
unexpected, then the concrete detail), after reading all 589 finished
entries in the live field: the field had stampeded into too-late knowledge,
centimetre teleports and rain over its own umbrella, so this entry takes a
mechanism with zero hits in the field — knowledge that only arrives by
destroying the check. The full draft list and duel record, including the
honest head-to-head estimates against the field's five strongest lines, are
in [candidates.md](candidates.md).

## Run

```sh
python3 main.py   # writes /output/entry.txt and prints the superpower
```
